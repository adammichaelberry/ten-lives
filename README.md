# Ten Lives — CFB survivor pick optimiser

Static site + GitHub Actions. Free to host on GitHub Pages.

## One-time setup (≈5 minutes)

1. **Create a repo** on GitHub (public is fine — the only secret is the ntfy topic).
   Upload `index.html`, `fetch_data.py`, `kickoff.py` (and the spreadsheet if you like). Then
   *Add file → Create new file*, name it `.github/workflows/tenlives.yml` and paste that file's
   contents — typing the slashes creates the folders. `data.js` is generated by the workflow.
2. **Enable Pages:** Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`.
   Your app will be at `https://<you>.github.io/<repo>/`.
3. **Secrets** (Settings → Secrets and variables → Actions → *Secrets*):
   - `NTFY_TOPIC` — an unguessable topic name, e.g. `tenlives-4f9k2q`. Install the ntfy app
     (iOS/Android), subscribe to that topic. Your mate does the same. That's the whole push setup.
   - `SHEET_URL` *(optional)* — a direct-download link to the comp spreadsheet.
     Google Sheet shared with you: `https://docs.google.com/spreadsheets/d/<ID>/export?format=xlsx`.
     Dropbox/OneDrive links work if they download directly. Without it, use **Load .xlsx** in the
     app (stays in your browser) or commit the file to the repo.
4. **Variables** (same page, *Variables* tab, both optional):
   - `MOVE_ALERT` — points of line movement that triggers a ping (default 3).
   - `QUIET_HOURS` — Sydney hours to suppress kick-off pings, e.g. `23-7`. Empty = never quiet.
5. **Actions → "Ten Lives" → Run workflow** once to publish the first `data.js`.

## What runs when

One workflow (`tenlives.yml`), four schedules:

| When | Task | Does |
|---|---|---|
| every 6 h (+ extra Saturday runs) | data | ESPN, FPI, Sagarin, comp sheet, app-published picks → `data.js`; line-move pings |
| every 5 min Thu–Sun | gameday | for each of your picks: kick-off soon, end of each quarter, 2-minute warning, final |
| Thursday ~15:00 Sydney | bulletin | where you stand, picks locked so far, the ten leading picks with reasons, market-vs-model gaps |
| Monday 06:00 Sydney | report | weekly wrap: your results, rivals, ladder, top-10 for next week with reasons |

Run any task by hand: Actions → Ten Lives → Run workflow → choose the task.

The page itself also pulls live ESPN lines, scores and FPI every time it's opened.

## Alerts you'll get

- **Line moved** — any pool team whose line worsens by ≥ `MOVE_ALERT`, or any of *your* picks
  moving either way; high priority if one of your picks drops below the 21-point "comfortable" line.
- **Game day** — for each of your picks: kick-off ~45 min out (with radio links), score at the end of
  every quarter, a 2-minute warning (high priority if it's close), and the final with life impact.
- **Monday wrap** — results, rivals' week, ladder, next week's top ten with reasons.

## Local use

`pip install requests openpyxl`, then `python fetch_data.py --bundle` → `tipping.html` (single shareable file).

## Rules encoded

Big Ten / SEC / Big 12 / ACC + Notre Dame · 6 picks in weeks 1–3, then 5 · 13 regular-season weeks ·
each team once · non-FBS opponent or bye = illegal pick (counts as a lost life) · ten lives.
